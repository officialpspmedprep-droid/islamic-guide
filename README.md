🌙 Islamic Guide - PSP

A comprehensive Progressive Web App (PWA) featuring detailed stories of all 25 prophets, prayer guides, and Islamic knowledge based on authentic Quran and Hadith sources.

✨ Features

📖 25 Prophets Stories - Detailed biographies with Quranic verses and lessons
🕌 Five Daily Prayers - Complete guide with rak'at counts and benefits
🌙 Tahajjud Guide - Special section for night prayers
🙏 Salah Method - Step-by-step prayer instructions
📱 Responsive Design - Works perfectly on mobile, tablet, and desktop
⚡ Fast Loading - Optimized for performance
🔄 PWA Support - Installable on devices

🚀 Live Demo

Visit the live site: https://islamic-guide-psp.netlify.app/

🛠️ Technology Stack

Frontend: HTML5, CSS3, JavaScript
Icons: Font Awesome 6.4.0
Hosting: Netlify
PWA: Service Worker, Web App Manifest

📱 Sections

- Daily Prayers - Fajr, Dhuhr, Asr, Maghrib, Isha with benefits
- All Prophets - Adam to Muhammad (PBUH) with detailed stories
- Tahajjud Prayer - Night vigil prayer guide
- Salah Method - Complete step-by-step prayer instructions
